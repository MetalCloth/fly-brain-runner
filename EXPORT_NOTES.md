# Portable export

This copy contains the Fly-Brain Runner source, documentation, data, selected
checkpoint, and read-only Android observations.

The local `.venv`, Python caches, and historical generated training archives
are left out of the portable export. Recreate the environment from
`requirements.txt`; the original workspace still contains the complete local
experiment history.

The selected checkpoint is validated on the simulator. Android artifacts are
watch-only observations; this project does not claim real-game competence or
control.
